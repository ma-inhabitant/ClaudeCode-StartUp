# 初心者ガイド — 株の自動売買をやさしく

このガイドは、**株取引がはじめての人**でも、このプロジェクトで何をやろうとしているかが
わかるように書いた解説です。専門的な要件は [`../CLAUDE.md`](../CLAUDE.md) にありますが、
まずはこちらを読んでください。難しい言葉は出てきたら、その都度かみくだいて説明します。

> 💡 わからない言葉が出てきたら、末尾の「[用語集](#用語集)」を見てください。

---

## 1. このプロジェクトは何を作るの？

**「株を自動で売り買いするプログラム」** を作ります。

普通、株は人間が「今だ！」と思ったタイミングで自分で売買します。
それをコンピュータのプログラムに任せて、**決めたルールどおりに自動で売買**させるのが
「自動売買システム」です。

ただし、いきなり本物のお金で自動売買するのはとても危険です。
だから**安全な順番**で少しずつ進めます。

---

## 2. 安全に進める「3つの段階」

料理にたとえると、こんな流れです。

```
段階1：試作            段階2：リハーサル        段階3：本番
（バックテスト）   →   （ペーパートレード） →  （実際のお金で運用）
過去のデータで          今の株価で              本物の1万円で
「昔ならどうだった？」   架空のお金で練習         少額から
お金のリスク：なし      お金のリスク：なし        お金のリスク：あり
```

### 段階1：バックテスト（いま準備しているのはココ）
「**昔の株価データ**を使って、もしこの売買ルールを使っていたら儲かっていたか？」を
コンピュータで計算して確かめます。過去のテストなので、**お金は1円も動きません**。
まずはここをしっかり作って、良い売買ルールを見つけるのが目標です。

### 段階2：ペーパートレード（リハーサル）
段階1で良さそうなルールが見つかったら、今度は**今リアルタイムの株価**を使って、
**架空のお金**で売買の練習をします。これも**本物のお金は使いません**。
プログラムが実際の場面でちゃんと動くかを確認します。

### 段階3：本番運用（実際のお金）
ここで初めて**本物の1万円**を使います。あなたは少額から始めたいとのことなので、
**1株ずつ買える「単元未満株」**を使い、しかも **「売買のタイミングはプログラムが教えるが、
注文ボタンを押すのは自分」** という半自動のやり方で、安全に慣れていきます。

> 👉 **今やっているのは段階1の準備だけ。お金が減る心配はまだ一切ありません。**

---

## 3. なぜ「1万円」だと工夫がいるの？

日本の株には、ちょっと変わったルールがあります。

- **日本株は普通「100株セット」でしか買えません**（これを「1単元」と呼びます）。
  - 例：1株1,000円の会社の株を買いたい → 100株セット＝**最低10万円**必要。
  - つまり**1万円では買える株がほとんどありません**。

そこで使うのが **「単元未満株（たんげんみまんかぶ）」** というサービスです。
- これは **「1株から買える」** 特別なしくみ。証券会社ごとに名前が違います。

| 証券会社 | サービス名 |
|---|---|
| SBI証券 | S株 |
| 楽天証券 | かぶミニ |
| マネックス証券 | ワン株 |
| auカブコム証券 | プチ株 |

これを使えば、1万円でも数社の株を1株ずつ買えて、**分散**（卵を1つのカゴに盛らない）が
できます。

### ひとつ注意：「自動で注文」はできない
単元未満株は便利ですが、**プログラムから自動で注文を出す機能（API）がほぼありません**。
なので段階3では、

- **プログラム**：「この株を1株、今買うといいよ」と**教える**（自動）
- **あなた**：スマホアプリで**実際に注文ボタンを押す**（手動）

という **「半自動」** の形で進めます。完全な全自動ではありませんが、少額・初心者には
これが一番安全で現実的です。

## 4. 「売買ルール（戦略）」ってどう決めるの？

**戦略（せんりゃく）** とは、「**どんなときに買って、どんなときに売るか**」の決まりごとです。

- かんたんな例：「株価が上がり始めたら買う／下がり始めたら売る」
- 私たちは最初、こういう**シンプルなルール**から始めます。

将来は **機械学習（きかいがくしゅう）** という技術も使えます。これは、
コンピュータに**過去の大量のデータを見せて、売買のコツを自分で見つけさせる**方法です。
ただし最初から使うと複雑なので、**まずは簡単なルールで土台を作ってから**取り入れます。

---

## 5. 「損をしすぎない」ための仕組み（リスク管理）

自動売買でいちばん大事なのは、**儲けることより「大損しないこと」** です。
このプロジェクトでは、次の安全装置を必ず入れます。

- **損切り（そんぎり）**：「これ以上下がったら売る」ラインを決めておき、**自動で売る**。
  → やけどが広がる前に手を引くイメージ。
- **利確（りかく）**：「ここまで儲かったら売る」で**利益を確定**する。
  → 「もっと上がるかも」と欲張って失敗するのを防ぐ。
- **ポジションサイズ管理**：1つの株に**お金を集中させすぎない**ようにする。
- **最大ドローダウン制限**：全体の資産が**ある程度減ったら、いったん売買を止める**。
  → ブレーキ装置。
- **取引コストを計算に入れる**：株の売買には**手数料**がかかります。1万円のような少額だと、
  この手数料が利益を食べてしまいやすいので、最初からちゃんと計算に入れます。

## 6. これまでに決めたこと（かんたんまとめ）

| 項目 | 決めたこと | ひとことで言うと |
|---|---|---|
| 使う言語 | Python | 株の分析でよく使われるプログラミング言語 |
| 進め方 | バックテスト → リハーサル → 本番 | 安全な順番で少しずつ |
| 戦略 | まず簡単なルール、将来は機械学習 | コツコツ育てる |
| データ | J-Quants（JPX公式） | 日本株の過去データの入手先 |
| 対象の株 | 東証プライムの人気銘柄から | 売買しやすい有名どころから |
| お金 | 約1万円から | 少額スタート |
| 本番のやり方 | 単元未満株で半自動 | 1株から、注文は手動 |

## 7. これから決めると良いこと

あせらなくて大丈夫です。下のことは、これから一緒に少しずつ決めていきます。

- どんな簡単なルールから試すか（例：移動平均という指標を使った作戦）
- どのくらいの期間のデータでテストするか
- 損切り・利確を何％にするか
- プログラムが出した「買い／売りのサイン」をどう受け取るか（メモ・通知など）
