## ★最重要の結論（2026-06）— まだ「持ち続け」に勝てていない

実データ（日米の大型優良株, 2015–2023）での厳密な検証（ウォークフォワード・コスト込み）で、
**現状の全戦略（移動平均クロス / トレンドフィルター / ML / 横断モメンタム）が、単純な
バイ&ホールド（等金額で買って持ち続ける）にリターン・シャープ・最大DDのすべてで敗北**している。

- 例（米国, 7年OOS）: WF戦略 +28.6% vs 持ち続け +250.4%。横断モメンタムも +93% vs +585%。

### 教訓1 — 価格ベースの売買タイミング/選別は価値を破壊しがち
daily足の「売買タイミング当て」「上位選別」は上昇相場の大型株では価値を破壊しがち。
**新戦略は必ずバイ&ホールドと比較**し、勝てて初めて意味がある。手チューニングで一期間の
数字を追うのはオーバーフィッティング（ウォークフォワードで判断する）。

### 教訓2 — 利確はモメンタム系と相性が悪い
**利確(take_profit)はモメンタム系と相性が悪い**（大化け株を途中で売る）。
利確オフで米国モメンタムは -30%→+93% に改善。`take_profit_pct: null` + `trailing_stop_pct` が定石。

### 教訓3 — 日本株は資金額で「分散できる銘柄数」が変わる
整数株丸めのため。実測（日本株30銘柄・等金額）:
1万円→2/30銘柄(投資率4.8%)、**5万円→19/30(47.5%)**、10万円→26/30、30万円→29/30。
→ このため**初期資金を1万円から5万円へ引き上げ**た（2026-06）。なお戦略の優劣（持ち続けに負ける）は
金額に依らず不変で、5万円でも持ち続け+131% vs 戦略+21%。

### 教訓4 — ロングショートも当期間は赤字
**ロングショート（上位ロング・下位ショート, 研究用 longshort コマンド）も当期間は赤字**
（米国 -30%/-11%・日本 -29%）。市場中立にはなるが、モメンタム効果自体が 2015–2023 の
大型株では機能せず（2020年の急反転が直撃）。ショートは本番(5万円・単元未満株)では非対象。

### 教訓5 — 防御的オーバーレイ（下落回避）も機能せず
**防御的オーバーレイ（方向B, defensive コマンド）＝下落回避も機能せず。**
単純な長期MAのレジーム判定（trend=100/150/200）では最大DDを安定して減らせず（日本は悪化）、
リターンは大幅に犠牲（米国 +319%→+109%等）。MA市場timingはダマシで価値を生まない（学術知見と整合）。

### 残る方向性
別ユニバース（中小型・新興・セクター分散）/ ファンダメンタル等の特徴量 /
「相対強弱」ターゲット / リバランス頻度・コストの精緻化。

### 現状の到達点（重要）
ロング専用4戦略＋ロングショート＋防御オーバーレイの**計6アプローチがすべてバイ&ホールド
（等金額インデックス持ち続け）に未勝利**。価格ベースの売買タイミング/選別/下落回避は
当該大型株(2015–2023)では価値を生まないと一貫して確認。
→ 示唆: 初心者・少額には「分散バスケットを淡々と持ち続ける」が現状データ上は最良。
さらなる挑戦は別ユニバース/別データ（ファンダメンタル）が要る。検証基盤
（ベンチマーク・ウォークフォワード・長短・防御）は完成しており、仮説検証の土台は整った。

### 採用した現実路線（方向E）
**「分散バスケットを積立で買い増して持ち続ける」を正式な推奨とし、仕組み化した。**
`plan`（予算内で“分散に最も足りない銘柄から1株ずつ”買うお買い物リスト＝上がる予想ではない）と
`accumulate`（積立シミュレーション）を実装。実データ(JP30銘柄,2015-2023,5万+毎月1万)で
投入112万→235万(+110%)。売買タイミングではなく時間と分散積立で増やすのが趣旨。
